# Task 002: Layer 2 -- extend the port derivation to the full set (210 faces)

## Objective

Card 001 built the derivation and proved it on 11 pilot + 3 holdout faces.
Card 002 extends it -- **without adding per-card branches** -- to run cleanly on
every face in `data/normalized/faces.jsonl` and produce a
`data/graph_global/card_ports.jsonl` covering all 210 faces with no ability left
unresolved and no concept left undeclared.

The mechanism from Card 001 stays put. What changes is the *vocabulary* and the
*trigger table*: whatever the reviewed extraction says across the whole set must
land in the port as a typed edge, not in `unresolved`.

## Acceptance Criteria

- [x] `data/graph_global/card_ports.jsonl` carries exactly 210 port records, one per face in `data/normalized/faces.jsonl`
- [x] Zero unresolved abilities across the full set
- [x] Zero undeclared concepts across the full set -- every concept a record references is declared in `data/vocabulary/concepts.jsonl`
- [x] Zero selector-in-name anti-pattern hits on non-`event:` targets
- [x] Every effect verb observed across the set maps through `data/vocabulary/op_map.jsonl`; an unmapped verb fails the run naming face, ability and verb
- [x] No face id, card name, or per-card branch is added to `src/hobkg/ports.py` -- the Card 001 anti-transcription test still passes
- [x] `derive_all(..., all_faces=True)` and the `--all` CLI flag run the derivation over every normalized face
- [x] `--all` and `--face` are rejected together with a non-zero exit
- [x] Ability-level costs are lifted for all eight families (mana, sacrifice, tap, life, discard, crew, restriction, additional_cost), not mana alone
- [x] Self-ETB triggers are split by printed subject type per CR 603.6a, rather than collapsing to one broad permanent-enters event
- [x] Native keywords encoded inside an effect land in `properties.HAS_KEYWORD`, not `produces.GRANTS`
- [x] `tests/test_ports.py` covers the full-set invariants under a `test_card_002_*` prefix and the whole suite passes

- `data/vocabulary/op_map.jsonl`: **33 -> 185 rows (+152)**, in five buckets:
  (1) aliases for verbs that entered as `effect:` / `action:` / `type:` rather
  than `op:` (same predicate, extra source_key row); (2) new predicates for
  common Magic actions the pilot never exercised -- `PRODUCES_MANA`, `TUTORS`,
  `GAINS_LIFE`, `UNTAPS`, `SCRIES`, `MILLS`, `COUNTERS_SPELL`, `FIGHTS`;
  (3) novel HOB mechanics -- `RECRUIT`, `ADVENTURE`, `TYPECYCLING`, `KICKER`,
  `FLASHBACK`, `BEHOLDS`, `AMASSES`, and one keyword-key verb;
  (4) conditional modifiers -- `MODIFIES_COST`; (5) structural markers --
  `MODAL_MARKER`, `RESTRICTION`.

- `data/vocabulary/concepts.jsonl`: **32 -> 135 rows (+103)**. 37 Event concepts
  (29 initially, 8 more once the specific-selector event names turned out to
  need declaring) for the 89 distinct trigger phrases now handled by
  `map_trigger_to_event()` -- phase-step, sacrifice, draw, damage,
  exile-replacement, saga-chapter, dwarf/equipment enters, land enters, artifact
  enters, this-permanent enters, and specifics like
  `event:total-attack-power-12-or-greater`. Plus 66 ObjectClass / Keyword
  concepts (48 supertype/subtype harvested from the normalized face type_lines,
  18 ability-keyword concepts from the extraction), which closed the last
  undeclared-concept gap.

### What Card 002 changed -- derivation

- `map_trigger_to_event()` grew from a 6-branch pilot map to a structured,
  ordered matcher covering all 89 trigger phrases across 210 faces. Ordering
  matters: saga-chapter before generic counter, enter-selectors before bare
  `_enters`. Bare forms (`dies`, `attacks`, `_enters`) and subject-name
  self-references (`smaug_attacks`, `The Master of Lake-town dies`, `Dain enters
  the battlefield`) all fold to the correct `event:this-creature-*`.

- `KEYWORD_VERB_KEYS = ("amass",)` -- some Magic keyword-actions arrive as a
  top-level *key* in the effect dict (`{"amass": {...}}`) rather than a *value*
  on `op` / `effect` / `action` / `type`. When the standard keys are absent the
  effect loop tries these fallback keys with `source_key == verb`.

- Ability-level cost lifting expanded from mana-only to eight cost families. The
  pilot silently dropped every non-mana ability-level cost -- Allure of Power's
  "sacrifice a creature", Lonely Mountain's `{T}`, My Precious's "pay 2 life",
  the discard costs on cycling -- because the effect processor only saw them
  when an accompanying effect referenced them. The cost loop now emits typed
  edges (SACRIFICES / TAPS / PAYS_LIFE / DISCARDS / CREW / RESTRICTION) with
  `purpose="cast"` for spell_effect abilities and `purpose="activation"` for
  activated abilities.

- Descriptor sweep, pass 2: `PRODUCES_MANA` lifts `mana` / `color` / `colors` /
  `options`; damage effects lift `amount` / `target_text` / `distribution`; cost
  detection accepts `{"cost": "mana", "value": "..."}` alongside the op/type
  shapes; every edge with a natural-language target carries `target_text`;
  trigger `condition` / `filter` / `subject` / `timing` / `frequency` / `note`
  are lifted onto the `TRIGGERS_ON` edge.

- Manual-review sweep, four buckets. Bucket 1, token spec lift: `CREATES_TOKEN`
  / `GIFTS` / `CREATES_OBJECT` edges resolve the reference against Scryfall's
  token index and attach a full token block; modal effects unpack their
  `options` into typed sub-edges. Bucket 2, blank-endpoint fill: the entry
  builder lifts every descriptor field the extraction carries, so edges that
  rendered as bare `GRANTS_PERMISSION` or `REPLACES` now carry the extraction's
  own descriptor. Bucket 3: effect-level `condition` (singular) merges into the
  entry's `conditions` list, not just `ab.conditions` -- Beorn the Fierce is the
  pilot case. Bucket 4: compound triggers split, so "enters or attacks" emits
  both events.

- Self-ETB triggers split by printed subject type. "When this enchantment
  enters" fires only when the card enters *as an enchantment* (CR 603.6a), so
  each printed subject type gets its own event. Card-name self-references and
  bare "enters" with no printed type word land on `event:this-permanent-enters`.
  Oracle wording is ground truth, correcting the extractor's over-normalisation
  of "When Smaug enters" to the broad target.

- "As this X enters" replacement effects route to `installs.REPLACES_ON` rather
  than `consumes.TRIGGERS_ON`, keyed on `ab.kind == "replacement"`. Same event
  vocabulary, different predicate: reacting to an event versus changing what the
  event does.

- Effect descriptor lift picked up `counter_type`, `duration`, and token
  references the pilot dropped. Bifur's `ADDS_COUNTER` now reads
  `counter_type: "+1/+1"` and Beorn's reads `"trample"` -- the graph can tell
  them apart.

- Baseline power/toughness lifted into properties as `HAS_POWER` /
  `HAS_TOUGHNESS` (226 new edges across 113 permanents; non-numeric values like
  `"*"` or `"1+*"` pass through verbatim). These are as intrinsic to a
  permanent's port as its type line.

- Native-keyword detection extended past `ab.keyword`. The extraction encodes
  some native keywords inside an effect rather than promoting them, and Dori's
  trample, Smaug's flying and Large Bear's reach/trample/haste were all being
  wrongly emitted as `produces.GRANTS`. Self-reference tokens count as
  no-target for the native branch: `this creature`, `this permanent`, `this
  card`, and the card's own name.

- The selector-in-name check now exempts `event:` targets, since CR-defined
  trigger predicates legitimately embed a subject qualifier. Non-event targets
  still fail the check.
